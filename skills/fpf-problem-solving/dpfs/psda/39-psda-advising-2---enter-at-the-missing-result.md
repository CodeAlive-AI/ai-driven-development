## PSDA.Advising:2 - Enter at the missing result

The entries below are alternatives, not a work order. An adequate result can be reused; a material change can reopen one contribution without reopening the rest.

| Working question | Start here | First useful return |
| --- | --- | --- |
| What useful future contribution could be possible? | [Opportunity-construction Method (FPF C.40.OCN:1)](../../sections/09-part-c---kernel-extension-specifications/108-c-40-ocn---construct-a-bounded-opportunity.md#c40ocn1---problem-frame) | A candidate opportunity, dependencies, bounded reachability rationale and next question; no adviser is required. |
| Who is asking for what advice, and on what terms? | [Bound the advising engagement](40-psda-advising-3---bound-the-advising-engagement.md), using PSDA.11 | A recipient/holder/horizon question and service boundary, or the missing condition. |
| What facts about this holder could reverse the answer? | [Recover only the relevant holder premises](41-psda-advising-4---recover-only-the-relevant-holder-premises.md) | The holder's current configuration and facts or gaps that can change the decision. |
| Which specialist result is missing? | [Use the direct result-acquisition Method](42-psda-advising-5---use-the-direct-result-acquisition-method.md) | A useful qualified answer and its limit, a worthwhile bounded request, or a blocker. |
| Which directions are actually live, and how do they compare? | [Keep a qualified live candidate set](43-psda-advising-6---keep-a-qualified-live-candidate-set.md) and [Compare for this receiving use](44-psda-advising-7---compare-for-this-receiving-use.md) | A bounded set, comparison, partial order or discriminating question. |
| What can the recipient responsibly consider now? | [Compose the bounded recommendation](45-psda-advising-8---compose-the-bounded-recommendation.md) and [Return it for the agreed use](46-psda-advising-9---return-it-for-the-agreed-use.md) | One or more explicitly scoped recommendation dispositions with basis and limits. |
| Has something changed that affects earlier advice? | [Reconsider only affected advice](47-psda-advising-10---reconsider-only-affected-advice.md) | Retained, narrowed or blocked claims; a request to the practice responsible for an affected result; or a later recommendation. |

A qualified opportunity supplies a candidate basis to PSDA.5; PSDA.6, PSDA.7, PSDA.8, PSDA.9 supply comparison premises to PSDA.14; PSDA.15 handles an actual follow-up question. Each dependency applies only to the same relevant holder, configuration, use and horizon.
