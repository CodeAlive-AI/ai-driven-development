## Engineering.Reference:25 - Combine results and handle a missing input


Keep the project question visible. Each additional method should supply a result that helps answer it. FPF contributes general reasoning methods; the domain practice supplies its thresholds, specialized methods and evidence. Identify who will use the result and who can make the final decision.

Use [FPF A.15.9](../../../sections/07-cluster-a-v---constitutional-principles-of-the-kernel/24-a-15-9---use-or-request-a-bounded-result-from-another-practi.md) when another practice must supply one particular answer. State the subject and question, the conditions the answer must address, and how the answer will be used. Reuse an adequate existing result. Ask for new work only when the existing result is insufficient.

For example, a controller choice may need a fallback-safety conclusion, while a development recommendation may need a transfer assessment. Request that contribution with its evidence and limits. Continue independent work while the dependent decision remains open.

Begin with the first missing contribution, using earlier results whose conditions still hold. Before continuing, identify what the next action actually needs. A required missing input stops that action and its dependent continuation; keep the earlier usable result. If the missing input belongs only to an alternative or a stronger conclusion, continue the supported branch. State the missing result, the decision it prevents, and what new evidence, source, permission or other changed condition would allow that decision to be reconsidered.


### Engineering.Reference:25.1 - What must be available through the Method vertical?

A DPF describes reusable ways of working. Performing one of them needs the relevant constituent abilities, available resources and coordination, as well as a place in the encompassing work. The descriptions can cover one or several grains of that vertical. Reading them supplies neither the missing capability nor the shared resource.

Start with an action inside the work that matters. Use [FPF B.1.5.EW](../../../sections/08-part-b---trans-disciplinary-reasoning-cluster/07-b-1-5-ew---recover-how-constituent-actions-enact-encompassin.md) to recover what larger work is being performed through it now, then follow only the constituent connections that can change the result. Keep earlier preparation and external support visible with their own relations.

| Constructed working situation | Vertical during the selected action | What can change the continuation |
| --- | --- | --- |
| A dancer knows the figure and has adequate strength but loses balance in its rotation. | Muscular actions participate in maintaining balance through the turn; rhythmic steps and partner interaction participate in performing the same figure at that time. | HCD.3 and MDPE.10 locate the capability question. [SOM.1](../../human-capability-engineering-dpf-suite/som/09-som-1---model-the-bodily-contribution-to-a-movement.md) relates the dancer's experience, attempted adjustment and observed failure; SOM.2–4 address a missing distinction, regulation or combination, and SOM.5 a changing support relation. [RHY.12](../../rhy/25-rhy-12---develop-rhythmic-capability-through-representative.md) supplies rhythmic practice when that relation is the difficulty. Follow the result into a useful next move. Retain attained abilities; obtain support or practise the missing intermediate contribution; change an infeasible combination; or narrow what the current result establishes. Sum demands on genuinely shared resources over the relevant intervals. Distinguish the conditions needed to start, those maintained during the combination and the result the whole must produce. Passing a local test establishes only the contribution that test addresses.

[FPF A.22.CGUS](../../../sections/07-cluster-a-v---constitutional-principles-of-the-kernel/50-a-22-cgus---which-continuations-are-available-constraint-gov.md) uses these conditions to distinguish available, unavailable and unknown continuations. A suitable practice branch can remain available when full performance is not. A temporal arrow or a nested flow position alone does not express the constituent connection. The pattern's ordinary question is useful without constructing a formal diagram.


### Engineering.Reference:25.2 - When does learning a movement also require developing its teaching?

Start with the movement that the person wants to use, and the conditions in which it must work. An unsuccessful attempt can reflect an unavailable bodily contribution, a problem with the technique or an external condition. [HCD.3](../../human-capability-engineering-dpf-suite/hcd/18-hcd-3-diagnose-whether-a-capability-misconception-or-behavio.md) examines what limits the performance. [SOM.1](../../human-capability-engineering-dpf-suite/som/09-som-1---model-the-bodily-contribution-to-a-movement.md) helps relate a proposed bodily correction to the performer's experience, available regulation and observed movement. Retain an effective change to the tool or conditions when it serves the task without additional bodily learning.

In a constructed case, a swimmer is preparing for a particular open-water event but has difficulty coordinating a familiar stroke in supervised pool practice. The swimming teacher supplies the technique, suitable conditions and criteria; the example does not establish a bodily cause. If an attempted correction exposes a missing bodily distinction, use SOM.2; for unavailable regulation, SOM.3; for a combination that cannot yet be recalled, SOM.4; for a failed transition as support or load changes, SOM.5. [HCD.6](../../human-capability-engineering-dpf-suite/hcd/22-hcd-6---design-representative-practice-tasks.md) places the selected contribution in suitable practice, and HCD.9 uses the next attempt to inform correction. Return to the stroke with the necessary concurrent actions. A clearer feeling in preparation does not establish that stroke, and a successful pool attempt does not establish readiness for the event.

**Ask whether the practice can be supplied.** [HCD.7](../../human-capability-engineering-dpf-suite/hcd/24-hcd-7---arrange-providers-access-tools-and-ai-support-for-hu.md) checks who can provide the needed demonstration, observe the attempt and give suitable feedback under the available conditions. If that help is already adequate and available, use it. The learner need not first learn to design their own training.

If HCD.7 identifies a missing contribution, [HCD.8](../../human-capability-engineering-dpf-suite/hcd/25-hcd-8---obtain-or-build-missing-human-capability-development.md) compares obtaining it with preparing a provider to supply it. For example, the learner may be able to obtain qualified help sooner and with less risk than learn to select and judge the exercises alone. If developing that teaching capability is worthwhile, define its own task and test it: can the provider choose suitable practice, recognize the relevant failure and supply useful feedback? One person can be both learner and practice designer, but their ability to perform the movement does not establish their ability to teach it. Conversely, a working teaching arrangement does not establish the learner's movement capability.

Learning to organize practice, preparing the bodily contribution, learning a swimming technique and preparing for an event can therefore be related development projects with different results. [HCD.2](../../human-capability-engineering-dpf-suite/hcd/20-hcd-2---compose-and-compare-human-capability-development-pro.md) compares ways to obtain the needed capabilities and support, retaining what is already available and accounting for dependencies and the burden of the alternatives. These projects are not four required stages or four levels of every movement. They may proceed at different times; the Method vertical above concerns what is enacted together within the selected action.

The next useful result is a suitable practice with the help it needs, a way to obtain or develop the missing teaching contribution, or a named gap that stops only the dependent work. Test each result in its receiving use.


### Engineering.Reference:25.3 - How can attention move while the whole action continues?

Use this route when an instruction such as “watch the contact”, “feel the support” or “notice the changed condition” is understandable, but following it leaves another necessary action unattended. The useful result is a workable way to obtain and use the information during the whole action, or a specific missing contribution. Keep a familiar effective routine when it already serves the purpose.

**Begin with what the observation changes.** Which response depends on the distinction, and when can that response still help? If the concept is understood but its participants cannot be found in the situation, [FPF B.5.4](../../../sections/08-part-b---trans-disciplinary-reasoning-cluster/41-b-5-4---recognize-a-reusable-concept-in-a-concrete-situation.md) recovers that correspondence. If the relation is known but the learner cannot discern it, [HCD.6.1](../../human-capability-engineering-dpf-suite/hcd/23-hcd-6-1---help-a-learner-discern-a-needed-distinction-in-pra.md) constructs a contrast around it. Neither a correct explanation nor a noticed difference establishes a bodily response.

**Recover how the information can arrive in time.** Follow the response backward under [FPF B.5.RC](../../../sections/08-part-b---trans-disciplinary-reasoning-cluster/28-b-5-rc---recover-a-construction-from-its-description.md): what must be observed, who can observe it, how it reaches the performer and what response is already available? Then work that construction forward. The receiving technique supplies the relevant event, means of observation and permitted response.

**Keep the simultaneous work in view.** Use the vertical above to identify what continues through that observation and response. [FPF C.32.MWA.PP](../../../sections/09-part-c---kernel-extension-specifications/83-c-32-mwa-pp---construct-and-compare-method-performance-and-p.md) compares arrangements at the moment their demands overlap. The performer might use a learned observation routine, obtain a teacher's cue or change a support arrangement. Compare serious arrangements, keeping unresolved conditions explicit. Perform only within the conditions currently available; moving a demand to someone else does not eliminate it.

In a constructed dance-learning case, a learner can make a taught bodily correction when prompted. During the figure, rhythm and partner interaction must continue, but inspecting each bodily part in turn disrupts them. [SOM.4](../../human-capability-engineering-dpf-suite/som/12-som-4---build-and-recall-a-coordinated-bodily-change.md) helps form and recall the combined change in suitable practice; detailed observations can be distributed across comparable attempts. Return to the whole figure with HCD.6/.9 and the dance teacher's technique. Use RHY where the rhythmic relation needs work. The teacher's observation can support practice without being credited as the learner's independent noticing.

Now suppose a required event can occur and disappear while the learner is attending elsewhere, and the response is needed before attention returns. A later look cannot recover that opportunity. An observer's cue can support the performance only if the observer can detect the event in time and the learner can receive and use the cue without losing the other contribution. If that combination is unavailable, change the task or support, or stop under the receiving practice's rule.

**Separate the repairs.** A missing bodily distinction calls for SOM.2; unavailable regulation for SOM.3; a failed combination for SOM.4; changing support for SOM.5. A missed or late observation may instead require another means of obtaining information. HCD.9 uses feedback to distinguish these failures. Choose among admissible continuations under [FPF A.15.7](../../../sections/07-cluster-a-v---constitutional-principles-of-the-kernel/21-a-15-7---situation-responsive-work-steering-and-next-action.md) only where a choice remains; follow an already prescribed response directly.

**Test the support on which the use depends.** When independent performance matters, remove an answer-bearing cue under suitable practice conditions and vary a feature that could have supplied a misleading shortcut. Where changing the workpiece length shifts when the required contact occurs, vary it to test whether the response follows contact or a memorized delay. [FPF A.15.8](../../../sections/07-cluster-a-v---constitutional-principles-of-the-kernel/22-a-15-8---work-performance-configuration-and-recovery-testing.md) examines the changed dependency; HCD governs practice and capability evidence. Retain useful supported performance while the independent contribution is still being learned.

The same construction question can arise in automated work, but a sensor, event-handling mechanism or learned policy needs its own technical construction and evidence. Attention need not visit every Method level in sequence: the required work must remain supplied while observations and corrections change.


### Engineering.Reference:25.4 - When the way of working is itself the problem

Use Method Engineering to examine the method, its descriptions and support. A pattern, a DPF and an instructional Guide can describe methods for different uses. An exact MethodDescription explains how one already identified Method is performed. Choose the representation for the work at hand: finding a method, understanding it, comparing alternatives or supporting performance. Use [FPF C.37.CF](../../../sections/09-part-c---kernel-extension-specifications/94-c-37-cf---compare-content-and-form-changes.md) when a revision changes the content or presentation and that distinction affects which version to retain. Actual performance supplies the results against which a method can be tested.

For connected Method Engineering questions, [FPF C.39.MC](../../../sections/09-part-c---kernel-extension-specifications/104-c-39-mc---continue-method-development-from-changed-condition.md) helps identify the result needed now, reuse an adequate earlier answer and revisit the claims affected by a new fact. These patterns supply contributions to select as needed; their links and reading order do not establish Method parts or prescribe a sequence through the whole language.

When a mathematical property could change the way work is divided or ordered, use [MMP.21](../../foundational-thinking-dpf-suite/mmp/27-mmp-21---compare-interacting-operations-through-mathematical.md) to compare the arrangements and [MMP.22](../../foundational-thinking-dpf-suite/mmp/28-mmp-22---construct-a-way-of-working-through-mathematical-tra.md) to construct the changed procedure. The [distributed-calculation example (MMP.21:5.4)](../../foundational-thinking-dpf-suite/mmp/27-mmp-21---compare-interacting-operations-through-mathematical.md#mmp2154---use-a-mathematical-construction-to-change-how-work-is-divided) follows a preserved mathematical answer into a proposed division of work, compares its burden, then revises the summaries when the recipient needs another statistic. Mathematical equivalence alone does not establish practical improvement.


### Engineering.Reference:25.5 - When source material should change a pattern language

Suppose a handbook, a research paper and an existing repertoire partly agree, but a recurring user still cannot recover a condition needed to act. The [source-grounded production specialization in FPF E.4.CM:4.8](../../../sections/11-part-e---the-fpf-constitution-and-authoring-guides/06-e-4-cm---develop-connected-methods-as-framework-contribution.md#e4cm48---produce-source-grounded-method-knowledge-in-pattern-language-form) explains how to turn those sources and current supply into usable Method-description knowledge in pattern-language form. It describes prospective performance without establishing a decomposition into part Methods; use B.1.5.CM/B.1.5 when a receiving use depends on that relation. Trial evidence is still needed to judge how that Method performs in practice.

Begin at the missing result. [FPF A.3.1.DR](../../../sections/05-part-a---kernel-architecture-cluster/22-a-3-1-dr---recover-method-contributions-from-documentary-sou.md) recovers what each documentary source actually contributes. [FPF F.0.2.MA](../../../sections/12-part-f---the-unification-suite-concept-sets-sensecells-and-system-role/03-f-0-2-ma---synthesize-and-allocate-method-contributions.md) uses the recovered meanings to decide what the existing repertoire already supplies and what should be added, changed or left at the source. [FPF E.8.ML](../../../sections/11-part-e---the-fpf-constitution-and-authoring-guides/21-e-8-ml---construct-a-pattern-language-for-connected-methods.md) organizes the needed descriptions and neighboring contributions around users' questions and the results they consume. [FPF F.0.2.RC](../../../sections/12-part-f---the-unification-suite-concept-sets-sensecells-and-system-role/04-f-0-2-rc---test-constructive-coverage-and-refresh-dependent.md) tests a promised source-to-language answer by reconstructing its action, conditions and source basis, then returns a loss to the affected description, allocation or language relation. A sufficient source passage or single MethodDescription is a valid stopping point.

For example, a handbook permits reusing a review after a display-only change, while a paper adds that the reviewed claims, question and qualification window must still match. F.0.2.MA keeps that condition with the checking guidance already supplied by [FPF A.3.1.CC](../../../sections/05-part-a---kernel-architecture-cluster/25-a-3-1-cc---check-the-coherence-of-a-method-claim.md). If the language says only “reuse for display changes”, F.0.2.RC identifies the missing condition and returns a description repair. Later, loss of access to an argument required for a new recheck can block that recheck while an earlier supported result retains its historical basis.


### Engineering.Reference:25.6 - When several management views describe the same work

Project, process and case management can answer different questions about the same work. [FPF A.15.6](../../../sections/07-cluster-a-v---constitutional-principles-of-the-kernel/20-a-15-6---recover-what-project-process-or-case-wording-refers.md) and [FPF E.17.0](../../../sections/11-part-e---the-fpf-constitution-and-authoring-guides/45-e-17-0---viewpoint-and-view-recognition-for-multi-view-descr.md) help recover that work and select useful views. Reconcile them at the shared work and decisions. A conflict between descriptions may need a description repair; a real conflict between contributions needs a working-arrangement decision.

For an operating plan that depends on another service's resources, evidence or permission, use [Coordinate Interacting Operating Structures (OPS.11)](../../management-dpf-suite/ops/43-ops-11---coordinate-interacting-operating-structures.md) to identify the concrete dependency and obtain compatible decisions from those responsible. Start with the proposed change and only the dependencies that can alter it. A change to organizational design belongs with OCE.


### Engineering.Reference:25.7 - When the case or a relied-on source changes

Find which conclusion used the changed premise. Reconsider that conclusion and its dependent decisions, keeping the results whose evidence and applicability still hold. Check the publication date and exact pattern when wording or source currentness matters.

For a change to semantic integration, use [SIE.11](../sie/31-sie-11---trace-semantic-change-and-revalidate-affected-uses.md). When affected uses of a changed claim must first be discovered, [FPF A.10.1](../../../sections/07-cluster-a-v---constitutional-principles-of-the-kernel/08-a-10-1---revalidate-affected-uses-when-a-relied-on-source-ch.md) supplies that discovery; the relevant domain method judges each actual dependence. For one known reliance, use its domain method. Use [FPF A.10](../../../sections/07-cluster-a-v---constitutional-principles-of-the-kernel/07-a-10---evidence-graph-referring-claim-bound-evidence-and-pro.md) when the source-to-use account is implicit or must remain replayable. Use [FPF G.11](../../../sections/13-part-g---discipline-sota-patterns-kit/13-g-11---decide-whether-and-how-to-refresh-sota-packs-and-rela.md) for currentness and worthwhile refresh. A changed system or situation without a changed source premise goes directly to its domain method. Compatible meaning, applicability and access can leave only a reference repair; an earlier result that still answers the current question can finish the use.

Finish the lookup when you have an answer usable for the current decision, or a specific missing contribution that determines the next work.
