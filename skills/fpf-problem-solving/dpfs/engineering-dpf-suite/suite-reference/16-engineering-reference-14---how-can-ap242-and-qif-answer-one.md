## Engineering.Reference:14 - How can AP242 and QIF answer one configuration-bound inspection question?

In this constructed case a quality engineer asks which QIF inspection plan and result concern feature `F` in released product-definition revision and configuration `R` at effectivity `E`. An existing answer can finish this lookup if its grounds cover that feature and configuration. Suppose the engineer also needs a repeatable way to obtain the answer when the applicable plan or inspection record changes. The following construction shows how to choose the meanings and relations that must survive that change. The two source models can remain separate.

**Establish what the engineer must be able to use.** [SIE.1](../sie/21-sie-1---bound-the-receiving-use-and-semantic-contract.md) helps establish the required answer, revision, configuration, effectivity, freshness and source authority. Agree how the engineer can act if an observation is missing, stale or tied to a different feature. Use an existing agreement where it already answers those questions. Select the rows and trace the query must return from those conditions. The responsible engineering and quality participants determine the released configuration, plan applicability and inspection acceptance within their authority.

Return the supported plan and inspection results for `R`, `F` and `E` with the sources that establish the connection. A complete report needs coverage of the required plan and observations. If an unresolved local AP242 extension affects one feature class, identify the affected rows and send that question to its owner. A known blocking observation can already decide a narrower question for the release authority. For the repeatable query, also supply the selection and mapping rules and the conditions under which the engineer can continue to use them. An applicable plan may change while its identifier stays the same. The query must use the applicable assignment and report a missing or conflicting one in time for the receiving work. The engineer can then use the procedure on the next revision within its stated conditions.

Pass the supported semantic conclusions to the people responsible for engineering and quality. They apply their own authority and requirements to configuration, plan approval and inspection acceptance. For an actual installation, establish the applicable sources, configuration, implementation and records to the extent the receiving question requires. Carry out an agreed test or obtain new evidence when the existing grounds leave a necessary claim unresolved. To report a particular query or inspection as performed, establish that event.
