## MKT.Reference:8 - Consequences - What changes in practice?

The team can make a smaller justified promise, obtain a missing contribution, stop an unnecessary inquiry, or decline an unsuitable programme before creating unsupported reliance. Customer knowledge can change actual provision. Shared preparation can be used where it remains adequate, with exceptions and continuing service included in the comparison. A negative or uncertain result can change the next decision or show which claim the evidence supports.

This work also costs time. Jointly shaping a result, qualifying evidence, obtaining commitments and supporting exceptions can be more expensive than producing campaign materials. Use existing qualified results and direct local methods where sufficient. Deeper construction is warranted when it changes the available offer, its assurance or the whole burden.

Using the descriptions can take time to learn the language, find and adapt a method, check an AI contribution or maintain an explanation. Compare that cost over a named range of uses if it matters to adoption. Count shared development once. For each use, include the labour, service charges or computing capacity it requires.
