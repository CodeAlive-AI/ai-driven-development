## OPS.Reference:3 - Work, descriptions, structures, and records remain distinct


Work is admitted under its own conditions. Project, programme, process, case, queueing, and control views describe or coordinate Work for different questions; they do not create rival Work kinds. To identify an existing operating structure, establish which parts participate and which relations hold between them. A board, diagram, mathematical graph, event log, case file, model, or dashboard is a representation or record with a bounded use.

Name the structure relevant to the decision. For example, transformations connect inputs and results, while a resource dependency connects an activity to the capacity it requires. Commitment, event, case-state and control relations can answer other questions. If you use a graph, specify what its nodes and edges represent and how the result will be used.
