## RMP.Reference:5 - Criticism comes before method prestige
Explain how the design’s material could answer the question. Use a justified strategy when one is available. If a connection is missing, use C.39 with RMP.2. Work out what the answer must distinguish, recover a methodological operation that could distinguish it, and establish the connection from its premises or by following the operation on suitable material. A failed comparison can show which observation, arrangement or question needs to change or which particular result is missing. When choosing whether to pursue a study, compare the resulting strategy with the real alternatives, including finishing on current evidence.

Experiments, field observations, qualitative and reflexive inquiries, historical source criticism, computational models, evidence synthesis and mixed designs expose different errors. Use RMP.2 to ask which could reveal a relevant rival explanation, source misuse, bias, dependence, loss of context or unsupported transfer. Specify which finding would defeat or narrow the claim.

Consider alternatives when their evidence would make a difference to the answer. Hold a still-needed choice if an unavailable input prevents a justified selection. A plan may itself specify different operations for contingencies that the team can distinguish in time. Judge that whole strategy against the required criticism, feasibility and any accepted risk. If the allocation finishes as QualifiedNoNewStudy, that unknown can remain a limitation. Obtaining it is a separate commitment. After selecting a design, treat an input as a PostSelectionNeed only if every admissible combination of remaining values preserves the selected relation.
