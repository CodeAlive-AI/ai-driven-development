## RMP.Reference:7 - Use question qualification and design selection together

RMP.1 establishes whether research is needed and what knowledge would answer the question. RMP.2 determines what present evidence establishes and whether to select a feasible design, keep a needed selection open because a premise is missing, or finish without a new study while the evidence remains limited. Use both when the request leaves both questions open. Use either directly when its inputs are available.

For an ambiguous request, use [RMP.1:4.0](31-rmp-1-decide-whether-a-question-needs-research-and-when-to-s.md#rmp140---develop-the-question-from-available-material) if the distinction that would make the answer useful still has to be developed. Use the [qualification procedure](31-rmp-1-decide-whether-a-question-needs-research-and-when-to-s.md#rmp141---pattern-use-unfolding) to qualify the resulting question when needed. A source-based correction, an ordinary professional result or a specified gap can answer the current request. Where the inquiry meets the research conditions, the ResearchQuestionBrief gives RMP.2 the intended change in knowledge, the criticism to address and a useful point to finish. A colleague’s compatible brief can supply the same result.

With the brief and frame, use the [RMP.2 design comparison](32-rmp-2-choose-a-criticism-bearing-research-design-or-stop.md#rmp244---compose-serious-design-or-stop-options). Compare alternatives against the same question while varying how evidence could answer it. For the seal, a mechanism experiment and a field-transfer comparison address different relations. Historical source criticism and corpus synthesis offer another possible contrast. Existing evidence may also suffice. For a selected design, identify the error it could reveal and the threats left open. The [four disposition branches](32-rmp-2-choose-a-criticism-bearing-research-design-or-stop.md#rmp247---return-exactly-one-researchdesigndisposition) give the possible conclusions.

RMP.1 can finish when a source answers the question. RMP.2 can use that source work to compare the evidence with the brief’s answer condition. EvidenceSufficientStop means the evidence answers the question for this use. QualifiedNoNewStudy means no new study is selected and the evidence limit remains. Permission to finish the work can therefore coexist with an unresolved knowledge question.

If a design comparison changes the question, intended use or useful stopping point, revisit RMP.1. If it changes an instrument, access condition or another selection premise, revisit the affected RMP.2 comparison. An infeasible preferred design can leave the question sound. A supplied answer or an identified hold can finish the current request.

An inquiry can produce several continuations with different answer conditions. Formulate the claim each branch would examine, identify the shared evidence, and state what possible finding would change a subsequent conclusion or action. Another analysis of shared material can expose dependence on an assumption. An independent source or a new intervention may be needed to decide between explanations.
