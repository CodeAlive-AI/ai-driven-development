# Edition and reuse

This publication contains fourteen methods, RHY.1–RHY.14, their applications and the conditions for using their sources. Cite Anatoly Levenchuk, the framework title, the edition date and the relevant PatternID or Architectural Reference address. To identify the passage you used, give a permanent link to the file at the commit you used or to an accessible archived copy. For rhythmic comparison, see [the earlier RHY.7](https://github.com/ailev/FPF/blob/1e57ccda08ebbb9d49b7b2190bc2740b72075a13/DPFs/EMBODIED-RHYTHMICS-PRINCIPLES-FRAMEWORK.md#rhy7---characterize-and-compare-rhythmic-structures-for-a-named-decision) and [the current RHY.7](20-rhy-7---characterize-and-compare-rhythmic-structures-for-a-s.md). To identify the property to compare, see [the earlier RHY.7:4.1](https://github.com/ailev/FPF/blob/1e57ccda08ebbb9d49b7b2190bc2740b72075a13/DPFs/EMBODIED-RHYTHMICS-PRINCIPLES-FRAMEWORK.md#rhy741---name-the-difference-the-receiving-choice-needs) and [the current RHY.7:4.1](20-rhy-7---characterize-and-compare-rhythmic-structures-for-a-s.md#rhy741---identify-the-rhythmic-difference-the-question-requires).
